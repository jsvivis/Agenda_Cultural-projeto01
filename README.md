# Sistema de Agenda Cultural Eletrônica

## Sobre o Projeto
O Sistema de Agenda Cultural Eletrônica é uma aplicação desenvolvida para facilitar a **gestão de eventos e programações culturais**. Ele possibilita a organização e visualização das atividades socioeducacionais promovidas pelo Instituto, superando desafios como:
- Gerenciamento de eventos em equipamentos distintos;
- Falta de integração entre tabelas;
- Carência de visualização unificada;
- Ausência de interatividade nos dados e suporte a anexos.

A aplicação foi projetada para unificar e apresentar dados de forma **interativa, funcional e de fácil compreensão**, organizando, otimizando e uniformizando o trabalho dos usuários e setores. O foco principal é aumentar o desempenho e a produtividade dos colaboradores no alcance das metas institucionais.

## Arquitetura e Recursos de Implementação do Projeto
As tecnologias e ferramentas utilizadas foram selecionadas para garantir eficiência, escalabilidade e uma experiência agradável ao usuário:

- **Node.js**: Por sua velocidade de desenvolvimento e configuração simples.
- **React**: Escolhido devido à sua popularidade, flexibilidade e ampla comunidade de suporte.
- **JavaScript e CSS**: Base para lógica de front-end e estilização, garantindo compatibilidade e adaptabilidade.
- **MySQL Workbench**: Para administração e manutenção do banco de dados de forma integrada.
- **MUI (Material-UI)**: Sistema de design que oferece componentes pré-estilizados e responsivos.
- **BigCalendar**: Exibe um calendário interativo, permitindo visualização, adição, edição e exclusão de eventos.
- **EventList**: Lista eventos futuros em ordem cronológica. Utilizamos a biblioteca **Axios** para buscar e gerenciar os dados de eventos.
